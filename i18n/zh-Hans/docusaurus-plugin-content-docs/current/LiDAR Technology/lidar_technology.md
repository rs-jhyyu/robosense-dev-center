# 激光雷达技术

本板块介绍速腾聚创激光雷达的产品与技术背景：扫描原理、点云特性、坐标系定义，
以及各产品线的性能规格。

本板块包含：

- [基础名词解析](lidar_terminology.md)——规格书中常见术语的解释：dToF 测距原理、
  准度与精度的区别、视场角、角分辨率、测距能力与反射强度。
- [常见现象解释](common_phenomena.md)——现场可能遇到的现象，如点云镜像、高反膨胀、
  玻璃目标识别与窗口片脏污，并说明各现象属于故障还是正常光学物理现象。

激光雷达连接与使用请查看[操作指南](../Getting Started/intro.md)，
产品手册与规格书请前往[手册/产品资料下载](https://www.robosense.cn/resources)。
