# 常见现象解释

本页解释使用激光雷达过程中经常遇到的几种现象，其中大部分属于正常的光学物理现象，而非硬件或算法故障。

点云镜像属于激光雷达在特定场景下的**正常光学物理现象**，并非激光雷达硬件或算法故障，原理如下：

1. 激光雷达发射的激光遇到光滑镜面（如**玻璃幕墙、水面、金属抛光面**等）时，大部分能量会发生镜面反射，不会直接返回激光雷达；
2. 这部分反射激光会照射到远处高反目标（如高楼、金属构件、高反广告牌等）上；
3. 高反目标会将激光能量沿原路反射回镜面，再经镜面反射回到激光雷达；
4. 激光雷达仅通过激光往返时间计算目标位置，无法识别传输过程中的偏折，因此会将这个“间接反射目标”误判为真实目标，形成镜像点（鬼影点）。

:::note
需要注意，实际工作场景中，镜面的面积可能非常小，由此产生的镜像点可能规模较小，部分场景可能会形成固定角度和位置出现的零星噪点，这类噪点往往会在特定角度和位置稳定出现。
:::

## 高反膨胀现象原理

当激光扫描到**高反射率目标物**（如高反板、金属镜面、白色高反墙面、交通标识牌等）时，会出现点云向四周扩散、目标看起来“变大”的现象，这就是“高反膨胀”，其核心成因如下：

1. **物理层面**：高反目标会反射极强的激光能量，导致激光雷达感光单元产生**热载流子溢出效应**，并向外发射近红外串扰光子；
2. **信号层面**：这些串扰光子会扩散到周围的感光单元，使周边像素被“误触发”，生成额外的虚假点云；
3. **表现特征**：膨胀出的点云**仅出现在高反目标边缘**，且反射强度显著低于真实目标点云，视觉上呈现为目标“变大、变模糊”；**其他非高反目标不会出现此类膨胀导致的尺寸拉长问题**。

## 玻璃目标识别

### 玻璃识别差异的核心影响因素

激光雷达对玻璃的识别效果，**高度依赖环境的特异性**，受以下关键因素共同影响：

1. **玻璃材质本身**：不同厚度、镀膜工艺、透光率的玻璃，对激光的反射/透射率差异极大；
2. **玻璃脏污程度**：表面附着灰尘、水渍、油污时，会改变激光反射特性，可能让玻璃从“几乎不可见”变为“可识别”；
3. **激光入射角**：激光照射玻璃的角度越接近镜面反射角，反射能量越容易偏离激光雷达，玻璃就越难被检测到；
4. **环境光强度**：强光环境下，环境光噪声会干扰激光回波信号，进一步降低玻璃目标的检测概率。

### 关于优化方案的客观说明

由于玻璃识别问题受**多维度、动态变化的环境因素**共同影响，该问题**难以通过统一标准量化**，因此不存在普适性的完美解决方案：

- 即使我们针对某一特定场景（如某块固定玻璃、固定入射角）做了针对性优化，当场景发生变化（更换玻璃、调整安装角度、环境光改变）时，优化效果也会大幅波动，无法保证在其他玻璃场景下达到预期效果；
- 强行针对单一玻璃环境做算法优化，可能会引入其他场景下的误识别、漏识别风险，反而影响整体点云质量。

### 更务实的业务建议

我们建议您将业务识别逻辑**从“直接识别玻璃”转向“识别玻璃周边易检测的实体目标”**，这是行业内应对此类问题的通用且高效方案：

- 优先识别玻璃的**金属边框、金属围栏、支撑结构**等：这类材质对激光反射率高、特征稳定，激光雷达可稳定检测，能间接实现“玻璃区域定位”的业务需求；
- 若您的业务是检测“玻璃区域是否存在遮挡/障碍物”，可通过检测周边金属结构的完整性、位置变化来间接判断，无需依赖玻璃本身的点云反馈。

## 窗口片脏污

### 窗口片脏污的常见成因及类型

#### 常见成因

激光雷达窗口片作为激光发射与回波接收的核心通道，直接暴露在使用环境中，脏污主要由以下场景导致：

- 户外/工业场景：灰尘、沙尘、飞絮、昆虫尸体、雨水残留、油污（如工业设备泄漏、车辆尾气）附着；
- 高湿度/低温场景：窗口片内外表面凝露、结霜，水汽凝结后吸附灰尘形成污渍；
- 人为/环境干扰：巡检操作中误触留下的指纹、水渍，或周边环境中的腐蚀性粉尘、化学污染物附着；
- 长期使用：窗口片表面磨损、老化，间接加剧脏污附着（磨损表面易吸附灰尘）。

#### 脏污类型及特征

- 轻度脏污：油污、厚层灰尘、干涸水渍，表面出现明显污渍痕迹；
- 重度脏污：厚层油污、腐蚀性污渍、大面积凝露结霜，或窗口片划伤、破损，严重遮挡激光传输通道。

### 脏污对激光雷达工作的核心影响

窗口片是激光雷达光学系统的关键组成部分，其清洁度直接决定激光传输效率、回波信号质量，脏污会从多维度影响设备工作，具体如下。

#### 影响点云质量，导致检测异常

- **激光散射与衰减**：脏污（如灰尘、水珠、油污）会使激光发射时发生散射、折射，导致激光能量衰减，回波信号强度降低，出现“点云稀疏、漏检”现象；
- **虚假点云生成**：脏污会反射、散射激光，触发激光雷达感光单元误触发，生成虚假点云（如高反膨胀加剧、无目标区域出现杂点），干扰目标识别与定位；
- **测距精度下降**：散射后的激光传播路径改变，激光雷达基于飞行时间（ToF）计算的目标距离出现偏差，影响避障、巡检等核心业务；
- **缺点少点**：脏污造成激光能量大幅衰减，部分激光无法正常反射回激光雷达，会出现明显的缺点、少点现象，导致目标轮廓不完整、漏检风险提升。

#### 触发设备报警，影响业务连续性

- 部分激光雷达具备窗口片脏污检测功能，脏污达到一定程度会触发“光学异常”“信号衰减”报警，导致设备停机或降级运行；
- 在自动驾驶、工业巡检等对设备稳定性要求高的场景，脏污导致的点云异常、测距偏差，可能引发业务中断、安全风险（如避障失效、巡检漏项）。

#### 与其他异常现象的关联

需特别注意：窗口片脏污会加剧高反膨胀、点云镜像等行业常见现象——脏污导致的激光散射，会放大感光单元串扰效应，使高反目标边缘的膨胀现象更明显；同时，散射激光可能经镜面反射形成额外镜像点，进一步干扰点云质量。
