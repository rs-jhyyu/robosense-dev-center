# 现有的 SDK 与驱动版本

以下是可用的预编译 SDK 和驱动软件包。当你需要支持默认 GitHub 仓库中未包含的激光雷达型号时，可使用它们。

| # | 版本 | 说明 | 下载 |
| --- | --- | --- | --- |
| 1 | rslidar_sdk v1.5.19 | 基线版本 | [rslidar_sdk-v1.5.19.tar.gz](pathname:///downloads/rslidar_sdk-v1.5.19.tar.gz) |
| 2 | 基于 rslidar_sdk v1.5.18 | 额外支持 **Fairy 48、AiryLite** | [rslidar_sdk.zip](pathname:///downloads/rslidar_sdk.zip) |
| 3 | 基于 rslidar_sdk v1.5.18 | 额外支持 **Fairy 48、EMX、EM4** | [rslidar_sdk_emx_em4.zip](pathname:///downloads/rslidar_sdk_emx_em4.zip) |
| 4 | 基于 rs_driver v1.5.18 | 额外支持 **EMX、EM4** | [rs_driver.zip](pathname:///downloads/rs_driver.zip) |

> 若需将 SDK 用于默认仓库未覆盖的激光雷达产品，请联系 RoboSense 技术支持以获取相应版本的软件包。
